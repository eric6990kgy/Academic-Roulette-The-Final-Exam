# 🎓 Academic Roulette: The Final Exam

用 React + TypeScript 做的《Buckshot Roulette》校園考試版——把「輪盤俄羅斯」的核心玩法整個重新包裝成「學生 vs 教授」的期末考生存戰，同一套機制換了一層完全不同的故事外殼。

一把槍變成一疊考卷，實彈變成「必死難題」，空包彈變成「送分題」；道具也全部重新設計成大學生活的日常物品，再搭配大量吐槽味十足的中文劇情文字，做成一款有頭有尾、三關破台的小遊戲。

---

## ✨ 玩法特色

- **學生 vs 教授**：雙方輪流「作答」，每次可以選擇自己作答或指定對方回答，抽到「必死難題」會扣血（學分），抽到「送分題」則安全過關。
- **三關式劇情**：微積分（極限與微分的深淵）→ 統計學（充滿陷阱的假設檢定）→ 初級會計學（借貸不平的無盡地獄），血量隨關卡遞增（2 → 3 → 5），越後面越硬。
- **5 種校園風道具**（原版道具的校園版重製）：

  | 道具 | 原版對應 | 效果 |
  |---|---|---|
  | 🔍 作弊小抄 | 放大鏡 | 偷看下一題是難題還是送分題 |
  | ☕ 冰美式 | 香菸 | 提神醒腦，恢復 1 點學分 (HP) |
  | 📄 請假單 | 啤酒 | 跳過當前題目（退掉一顆子彈） |
  | 🖊️ 當人紅筆 | 手鋸 | 下一題若是難題，扣分加倍 |
  | 👥 分組報告 | 手銬 | 把工作丟給對方，對手下一回合無法行動 |

- **大量客製劇情文字**：每一關、每種結果（學生命中／失手、教授命中／出包、送分題、過關、被當、獲勝…）都各自寫了 4~5 句對應該科目梗的吐槽台詞（羅必達法則、P-value、借貸平衡……），三關份的 `FLAVOR_TEXT` 加起來超過 200 句。
- **教授 AI**：依優先序決策——① 先用作弊小抄看牌、② 血量低就補冰美式、③ 有機會就用分組報告拖住學生、④ 視情況用紅筆加倍傷害。
- **程序化音效／配樂**：完全用原生 Web Audio API 現場合成鼓點與音效（menu／game 兩種背景配樂各自的 sequencer、開槍中彈/空包/補給/勝負音效），沒有用任何音訊檔案。
- **對話演出**：以類似視覺小說的方式彈出教授／學生的台詞對話框，搭配 Navbar 顯示目前關卡與科目名稱、靜音切換。

---

## 🛠️ 技術棧

- **React 19 + TypeScript + Vite 6**
- **lucide-react** — 圖示
- **原生 Web Audio API** — 自製音效合成器與音樂 Sequencer（`utils/audio.ts`，超過 300 行，無外部音訊檔案）
- 無額外狀態管理套件，遊戲狀態集中在 `App.tsx` 用 `useState` 管理

---

## 📁 專案結構

```
.
├── App.tsx               # 主遊戲流程：畫面切換、回合邏輯、教授 AI、對話演出（近千行）
├── constants.ts          # 道具資料、關卡資訊、三關份劇情台詞 (FLAVOR_TEXT)
├── types.ts              # 型別定義：ItemType、GameState、PlayerStats 等
├── components/
│   ├── Button.tsx        # 共用按鈕元件（variant/size 可調）
│   ├── GameLog.tsx       # 遊戲紀錄／戰鬥日誌，自動捲動到最新訊息
│   ├── ItemCard.tsx      # 道具卡片 UI
│   └── Navbar.tsx        # 頂部列：關卡/科目名稱、靜音切換、返回首頁
├── utils/
│   ├── gameLogic.ts      # 子彈生成、道具發放、回合輪替等純邏輯函式
│   └── audio.ts          # Web Audio API 音效／BGM 合成器
└── index.tsx             # React 進入點
```

## 💭 為什麼做這個

玩完 [Buckshot Roulette] 覺得這套「有限資訊 + 道具翻盤」的機制很好玩，就想練習看看同一套遊戲邏輯能不能換一個完全不同的主題重新說故事——於是把它包裝成每個大學生都懂的「被二一威脅」的期末考生存戰，順便把微積分、統計、會計三科的痛苦回憶都寫進台詞裡。
